# 手写笔压力曲线的分段三对角求解与重绘

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

目标为 Σ wi(pi-yi)^2+Σ λi(pi+1-pi)^2，非负权重，未观测 wi=0。固定锚点把该点的变量绑定已交付值。边的 λ i 作用于 point[i] 与 point[i+1]，仅在共享笔画且边 flagged=true 时生效。相同时间的连接边允许组成平滑项，无斜率结果。无固定锚点且全部 wi=0 的连通分量不唯一。斜率用相邻点求解差值除以相邻时间差，固定段边缘仍遵守有效边规则。有效压力误差不超过 1e-6。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。omit/refill 按点下标定位采样，refill 还给出测值与权重。edge 指边下标及其可用性。lock/dropAnchor 指锚点对应的点，read 指点下标半开区间。
